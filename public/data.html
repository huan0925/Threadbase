Back up & restore

Back up

Your chats are stored only in this browser. Removing Threadbase deletes them. Save a backup to keep them, or to move them to another computer.

The Markdown file is for reading. To restore, use the .json backup.

Restore

Import a .json backup. Chats you don't have yet are added. If you already have a chat, Threadbase keeps the newer copy. Nothing is deleted.
